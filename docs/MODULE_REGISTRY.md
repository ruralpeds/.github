## How This System Works

Every Rust module in this project is tracked with:
- **Created** — the date and git commit when the module was first added
- **Last Modified** — the date and git commit of the most recent change  
- **Source Documents** — the reference documents (saved in `module_source/`) that were used to design the module's clinical content

### Managing the Registry

```bash
# Register a brand-new module with a source document
./scripts/register_module.sh add-module src/protocols/allergy.rs \
    "Anaphylaxis and allergic reaction protocol" \
    /path/to/source_document.docx

# Attach a source document to an existing module
./scripts/register_module.sh add-source src/protocols/sepsis.rs \
    /path/to/surviving_sepsis_guide.pdf

# List all modules
./scripts/register_module.sh list

# Show detail for one module
./scripts/register_module.sh show src/protocols/sepsis.rs
```

The registry is **auto-updated after every git commit** via the post-commit hook.
