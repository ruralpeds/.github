Clinical Explanation
OI CALCULATION: MAP = 0.5×(PIP−PEEP)×(Ti/Ttot)+PEEP OI = (MAP×FiO₂×100)/PaO₂ Neonatal permissive hypercapnia: pH ≥ 7.25, PaCO₂ 45–55. Aggressive ventilation → volutrauma and BPD.
Decision Points
Decision Point 1
✓ Correct Action:
MAP = 0.5×(24−5)×(0.30/1.2)+5 = 7.375 cmH₂O. OI = (7.375×0.80×100)/38 = 15.5. TV 5.2 mL = 4.7 mL/kg actual weight (appropriate, 4–6 mL/kg). OI 15.5 — significant but not yet ECMO threshold (≥40). Increase PEEP to 6–7. Consider second surfactant dose (100 mg/kg).
⚠ Wrong Action Consequence:
Using IBW formula for infants risks volutrauma — use actual weight for TV in neonates.
Decision Point 2
✓ Correct Action:
OI 34.4 trending toward ECMO threshold of 40. Notify ECMO team NOW — do not wait for OI 40. Consider HFOV as lung-rescue. Consider iNO if PPHN component. Second surfactant 100 mg/kg = 110 mg if not given. Activate transport team if not at ECMO center.
⚠ Wrong Action Consequence:
Waiting until OI exactly 40 before ECMO notification creates dangerous transport delays.
Key Teaching Points
  • Neonatal TV: 4–6 mL/kg ACTUAL weight — never IBW in neonates
  • OI ≥ 40 on ≥ 3 measurements → ECMO threshold; notify team proactively
  • OSI = (MAP×FiO₂×100)/SpO₂ — surrogate when no ABG
  • Neonatal permissive hypercapnia: pH ≥ 7.25, PaCO₂ 45–55
  • HFOV and iNO are lung-rescue strategies before ECMO

Learning Objectives
  • Recognize CPAP failure in 28-week infant
  • Calculate initial vent settings (TV 5 mL/kg actual weight)
  • Calculate and interpret OI
