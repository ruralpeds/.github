# Pediatric and Neonatal Clinical Equations Reference

## CARDIOVASCULAR SYSTEM

| Equation Name | Formula | Variables | Units | Age-Specific Modifications |
|--------------|---------|-----------|-------|---------------------------|
| **Cardiac Output (CO)** | CO = HR × SV | HR = Heart Rate (bpm)<br>SV = Stroke Volume (mL/beat) | L/min | Proportionally lower in children based on body size |
| **Cardiac Output (Fick Method)** | CO = VO₂ / (CaO₂ - CvO₂) | VO₂ = Oxygen consumption (mL/min)<br>CaO₂ = Arterial O₂ content (mL/dL)<br>CvO₂ = Mixed venous O₂ content (mL/dL) | L/min | VO₂ estimation methods vary by age:<br>• LaFarge: Age/HR dependent<br>• Seckeler: All ages<br>• Adult: 125 mL/min/m² × BSA |
| **Cardiac Index (CI)** | CI = CO / BSA | CO = Cardiac Output (L/min)<br>BSA = Body Surface Area (m²) | L/min/m² | Normal: 2.6-4.2 L/min/m² (all ages when indexed) |
| **Stroke Volume (SV)** | SV = CO / HR | CO = Cardiac Output (L/min, convert to mL)<br>HR = Heart Rate (bpm) | mL/beat | Normal: 55-100 mL/beat (adults); varies with body size in children |
| **Stroke Volume (Echo - LVOT)** | SV = π × (D/2)² × VTI | D = LVOT diameter (cm)<br>VTI = Velocity time integral (cm) | mL | LVOT diameter typically ~2 cm in adults, smaller in children |
| **Stroke Volume Index (SVI)** | SVI = SV / BSA | SV = Stroke Volume (mL/beat)<br>BSA = Body Surface Area (m²) | mL/beat/m² | Normal: 33-47 mL/beat/m² |
| **Mean Arterial Pressure (Adult)** | MAP = (SBP + 2×DBP) / 3 | SBP = Systolic BP (mmHg)<br>DBP = Diastolic BP (mmHg) | mmHg | **Adult formula only** |
| **Mean Arterial Pressure (Neonatal)** | MAP ≈ (SBP + DBP) / 2<br>OR MAP = DBP + (0.466 × PP) | PP = Pulse Pressure = SBP - DBP | mmHg | **Neonatal-specific formula**<br>• Newborn (12h, <1000g): 28-42 mmHg<br>• Newborn (12h, 3kg): 48-57 mmHg<br>• 1-12 months: 50-62 mmHg |
| **Systolic BP (Pediatric Minimum)** | SBP (min) = 70 + (2 × age in years) | Age = Patient age (years) | mmHg | **Definition of hypotension:**<br>• Term neonate: <60 mmHg<br>• Infants 1-12 mo: <70 mmHg<br>• Children 1-10 yr: <70 + (2×age)<br>• Children >10 yr: <90 mmHg |
| **Systemic Vascular Resistance (SVR)** | SVR = 80 × (MAP - CVP) / CO | MAP = Mean Arterial Pressure (mmHg)<br>CVP = Central Venous Pressure (mmHg)<br>CO = Cardiac Output (L/min) | dynes·sec·cm⁻⁵<br>(Wood Units if omit ×80) | **Normal adult:** 700-1600 dynes·sec·cm⁻⁵<br>**Pediatric indexed:** 15-30 Wood Units·m² |
| **Systemic Vascular Resistance Index (SVRI)** | SVRI = 80 × (MAP - CVP) / CI | CI = Cardiac Index (L/min/m²) | dynes·sec·cm⁻⁵·m² | **Normal adult:** 1900-2300<br>Age/gestational age-specific nomograms available |
| **Pulmonary Vascular Resistance (PVR)** | PVR = 80 × (MPAP - PAWP) / Qp | MPAP = Mean PA Pressure (mmHg)<br>PAWP = PA Wedge Pressure (mmHg)<br>Qp = Pulmonary Blood Flow (L/min) | dynes·sec·cm⁻⁵<br>(Wood Units if omit ×80) | **Normal:** 20-130 dynes·sec·cm⁻⁵<br>**Pediatric indexed:** 2-4 Wood Units·m² |
| **Pulmonary Vascular Resistance Index (PVRI)** | PVRI = 80 × (MPAP - PAWP) / CI | CI = Cardiac Index (L/min/m²) | Wood Units·m²<br>(NOT /m²) | **Normal pediatric:** 2-4 WU·m²<br>**Operability:** PVRI <6 WU·m² OR PVR/SVR <0.3 |
| **QTc - Bazett (RECOMMENDED)** | QTc = QT / √RR | QT = QT interval (msec)<br>RR = RR interval (sec) | msec | **BEST for pediatrics**<br>**Prolonged if >460 msec** (age ≤6 yr)<br>Mean: 420-422 ± 20 msec |
| **QTc - Fridericia** | QTc = QT / ∛RR | QT = QT interval (msec)<br>RR = RR interval (sec) | msec | **FDA-recommended for trials**<br>**Prolonged if >414 msec** (age ≤6 yr)<br>Mean: 368-375 msec |
| **QTc - Hodges** | QTc = QT + 1.75 × (HR - 60) | QT = QT interval (msec)<br>HR = Heart Rate (bpm) | msec | Mean: 406-419 msec<br>Upper limit: 443-455 msec |
| **Ejection Fraction (EF)** | EF = [(EDV - ESV) / EDV] × 100 | EDV = End-Diastolic Volume (mL)<br>ESV = End-Systolic Volume (mL) | % | Normal: 55-70% |

## RESPIRATORY SYSTEM

| Equation Name | Formula | Variables | Units | Age-Specific Modifications |
|--------------|---------|-----------|-------|---------------------------|
| **Alveolar-arterial (A-a) Gradient** | A-a gradient = PAO₂ - PaO₂<br><br>Where: PAO₂ = (FiO₂ × [Patm - PH₂O]) - (PaCO₂ / RQ) | PAO₂ = Alveolar O₂ (mmHg)<br>PaO₂ = Arterial O₂ (mmHg)<br>FiO₂ = Fraction inspired O₂ (decimal)<br>Patm = Atmospheric pressure (760 mmHg at sea level)<br>PH₂O = Water vapor pressure (47 mmHg at 37°C)<br>PaCO₂ = Arterial CO₂ (mmHg)<br>RQ = Respiratory quotient (0.8) | mmHg | **Normal values:**<br>• Neonates: 20-30 mmHg<br>• Children: 10-20 mmHg<br>• **Age correction:** Normal A-a = 2.5 + (0.21 × age in years)<br>**Room air simplified:** A-a = 150 - (1.25 × PaCO₂) - PaO₂<br>**Interpretation:** ↑ A-a gradient suggests V/Q mismatch, shunt, or diffusion defect |
| **a/A Ratio** | a/A Ratio = PaO₂ / PAO₂ | PaO₂ = Arterial O₂ (mmHg)<br>PAO₂ = Alveolar O₂ (mmHg, calculated above) | Ratio (unitless) | **Normal:** >0.75-0.80<br>**Respiratory failure:** <0.60<br>**Advantage:** Less affected by FiO₂ changes than A-a gradient |
| **Oxygenation Index (OI)** | OI = (MAP × FiO₂ × 100) / PaO₂ | MAP = Mean Airway Pressure (cmH₂O)<br>FiO₂ = Fraction inspired O₂ (decimal)<br>PaO₂ = Arterial O₂ (mmHg) | Unitless | **Normal:** <5<br>**Mild HRF:** ≤15<br>**Moderate:** 16-25<br>**Severe:** 26-40<br>**ECMO consideration:** >40 |
| **Oxygen Saturation Index (OSI)** | OSI = (MAP × FiO₂ × 100) / SpO₂ | MAP = Mean Airway Pressure (cmH₂O)<br>FiO₂ = Fraction inspired O₂ (decimal)<br>SpO₂ = Pulse oximetry saturation (%) | Unitless | **Correlation:** OI ≈ 2 × OSI (when OI 5-25)<br>**Severe:** OSI >17.41 associated with ECMO |
| **PaO₂/FiO₂ Ratio (P/F Ratio)** | P/F Ratio = PaO₂ / FiO₂ | PaO₂ = Arterial O₂ (mmHg)<br>FiO₂ = Fraction inspired O₂ (decimal) | mmHg | **Normal:** >400<br>**Mild RF:** 200-300<br>**Moderate:** 100-200<br>**Severe:** <100 |
| **Respiratory Severity Score (RSS)** | RSS = MAP × FiO₂ | MAP = Mean Airway Pressure (cmH₂O)<br>FiO₂ = Fraction inspired O₂ (decimal) | cmH₂O | **Preterm:** RSS ≥6 on day 30 associated with increased mortality/prolonged ventilation |
| **Mean Airway Pressure (MAP)** | MAP = 0.5 × (PIP - PEEP) × (Ti/Ttot) + PEEP | PIP = Peak Inspiratory Pressure (cmH₂O)<br>PEEP = Positive End-Expiratory Pressure (cmH₂O)<br>Ti = Inspiratory Time (sec)<br>Ttot = Total cycle time (sec) | cmH₂O | **Normal lungs:** 5-10<br>**Preterm RDS:** 10-15<br>**ARDS:** 15-30 |
| **Static Compliance (Cst)** | Cst = VT / (Pplat - PEEP) | VT = Tidal Volume (mL)<br>Pplat = Plateau Pressure (cmH₂O)<br>PEEP = Positive End-Expiratory Pressure (cmH₂O) | mL/cmH₂O | **Term neonates:** 1.5-2 mL/cmH₂O/kg<br>**Preterm:** 0.3-1.5 mL/cmH₂O/kg<br>**Adult:** 70-100 mL/cmH₂O |
| **Dynamic Compliance (Cdyn)** | Cdyn = VT / (PIP - PEEP) | VT = Tidal Volume (mL)<br>PIP = Peak Inspiratory Pressure (cmH₂O)<br>PEEP = Positive End-Expiratory Pressure (cmH₂O) | mL/cmH₂O | Always ≤ static compliance<br>Chest wall 3× more compliant than lungs in first year |
| **Airway Resistance (Raw)** | Raw = (PIP - Pplat) / Flow | PIP = Peak Inspiratory Pressure (cmH₂O)<br>Pplat = Plateau Pressure (cmH₂O)<br>Flow = Inspiratory flow rate (L/sec) | cmH₂O/L/sec | **Neonatal:** 20-40 cmH₂O/L/sec (10-20× higher than adults)<br>**Intubated neonates:** 5-10 cmH₂O/L/sec |
| **Time Constant (τ)** | τ = Compliance × Resistance | Compliance (L/cmH₂O)<br>Resistance (cmH₂O/L/sec) | seconds | **Short (RDS):** <0.1 sec (allows high rates)<br>**Long (BPD):** >0.3 sec (requires low rates)<br>**Preterm inspiratory:** 0.2-0.4 sec |
| **Minute Ventilation (VE)** | VE = VT × f | VT = Tidal Volume (mL or L)<br>f = Respiratory frequency (breaths/min) | L/min or mL/min | **Neonates:** 0.2-0.3 L/min/kg (200-300 mL/min/kg)<br>**Term infants:** 240-360 mL/kg/min |
| **Alveolar Ventilation (VA)** | VA = f × (VT - VD) | f = Respiratory frequency (breaths/min)<br>VT = Tidal Volume (mL)<br>VD = Dead Space Volume (mL) | L/min or mL/min | **Anatomical dead space:**<br>• Neonates: ~1.5-2.2 mL/kg<br>• Larger in ELBW per kg |
| **Dead Space (Bohr-Enghoff)** | VD/VT = (PaCO₂ - PECO₂) / PaCO₂ | PaCO₂ = Arterial CO₂ (mmHg)<br>PECO₂ = Mixed expired CO₂ (mmHg)<br>VD = Dead space<br>VT = Tidal volume | Ratio (unitless) | **Normal:** 0.2-0.35 (20-35%)<br>**RDS infants:** 5.7 mL/kg<br>**BPD infants:** 6.4 mL/kg |
| **Tidal Volume (VT)** | VT = Flow Rate × Inspiratory Time | Flow Rate = Inspiratory flow (mL/sec)<br>Inspiratory Time = Duration (sec) | mL or L | **Neonates/preterm:** 4-6 mL/kg (lung-protective)<br>**Term infants:** 6-10 mL/kg by 1 year<br>**ELBW (23 wk, 500g):** Often start at 5 mL/kg |
| **Elastance** | Elastance = 1 / Compliance | Compliance (L/cmH₂O) | cmH₂O/L | Higher elastance = stiffer lungs (RDS)<br>Lower elastance = more compliant (BPD) |
| **Work of Breathing (WOB)** | WOB = ΔP × ΔV | ΔP = Pressure change (cmH₂O)<br>ΔV = Volume change (L) | cmH₂O/L or Joules | Neonates have higher WOB per kg<br>Preterm at higher risk of respiratory muscle fatigue |

## RENAL SYSTEM

| Equation Name | Formula | Variables | Units | Age-Specific Modifications |
|--------------|---------|-----------|-------|---------------------------|
| **Schwartz Equation (Original 1976)** | eGFR = (K × Height) / SCr | K = Proportionality constant (see below)<br>Height (cm)<br>SCr = Serum Creatinine (mg/dL) | mL/min/1.73 m² | **K values:**<br>• Premature (<1 yr): 0.33<br>• Term infant (1-52 wk): 0.45<br>• Children (1-13 yr): 0.55<br>• Adolescent female (>13 yr): 0.55<br>• Adolescent male (>13 yr): 0.70<br>**Note:** NOT for IDMS-traceable creatinine |
| **Bedside Schwartz (2009)** | eGFR = (0.413 × Height) / SCr | Height (cm)<br>SCr = Serum Creatinine (mg/dL, IDMS-traceable) | mL/min/1.73 m² | **Ages 1-16 years**<br>Single constant (0.413) for all ages and both sexes<br>Use with modern enzymatic creatinine assays |
| **Schwartz-Lyon (2012)** | eGFR = (k × Height) / SCr | k = Age/sex-specific coefficient<br>Height (cm)<br>SCr = Serum Creatinine (mg/dL) | mL/min/1.73 m² | **k values:**<br>• Children <13 yr & all females: k = 32.5<br>• Male adolescents >13 yr: k = 36.5<br>**Ages 1-18 years with mild/no renal insufficiency** |
| **Fractional Excretion of Sodium (FENa)** | FENa = [(Urine Na⁺ × Plasma Cr) / (Plasma Na⁺ × Urine Cr)] × 100 | Urine Na⁺ (mEq/L)<br>Plasma Na⁺ (mEq/L)<br>Urine Creatinine (mg/dL)<br>Plasma Creatinine (mg/dL) | % | **Interpretation:**<br>• **FENa <1%:** Prerenal azotemia<br>• **FENa >1-2%:** Intrinsic renal (ATN)<br>**Neonates (<1 month):**<br>• FENa <2.5%: Prerenal<br>• FENa >2.5%: Intrinsic<br>**Preterm (<32 weeks):**<br>• FENa <3%: Prerenal<br>• FENa >3%: Intrinsic<br>**NOTE:** Unreliable with diuretic use |
| **Urine Output Rate** | UO = Total UO (mL) / [Weight (kg) × Time (hr)] | Total Urine Output (mL)<br>Weight (kg)<br>Time (hours) | mL/kg/hr | **Normal values:**<br>• Newborn/infant (<1 yr): 2-3 mL/kg/hr<br>• Toddler (1-3 yr): 1.5-2 mL/kg/hr<br>• School-age (4-12 yr): 1-2 mL/kg/hr<br>• Adolescent (>13 yr): 0.5-1 mL/kg/hr<br>**AKI:** <0.5 mL/kg/hr for >6 hours |
| **Anion Gap** | AG = Na⁺ - (Cl⁻ + HCO₃⁻) | Na⁺ = Sodium (mEq/L)<br>Cl⁻ = Chloride (mEq/L)<br>HCO₃⁻ = Bicarbonate (mEq/L) | mEq/L or mmol/L | **Pediatric:** 8-19 mmol/L (median 13)<br>**Adult:** 7-18 mmol/L (median 13)<br>**Normal AG:** <12<br>**High AG:** >12 |
| **Urinary Anion Gap** | UAG = (Urine Na⁺ + Urine K⁺) - Urine Cl⁻ | Urine Na⁺ (mEq/L)<br>Urine K⁺ (mEq/L)<br>Urine Cl⁻ (mEq/L) | mEq/L | **Positive UAG (>0):** RTA<br>**Negative UAG (<0):** GI HCO₃⁻ loss<br>**Unreliable in neonates** (immature acidification) |
| **Serum Osmolality (Calculated)** | Osm = 2×Na⁺ + (Glucose/18) + (BUN/2.8) | Na⁺ = Sodium (mEq/L)<br>Glucose (mg/dL)<br>BUN = Blood Urea Nitrogen (mg/dL) | mOsm/kg H₂O | **Children:** 275-290 mOsm/kg<br>**Adults:** 285-295 mOsm/kg<br>**Osmolar gap:** <10 normal |
| **Corrected Sodium (Katz)** | Corrected Na⁺ = Measured Na⁺ + [1.6 × (Glucose - 100)/100] | Measured Na⁺ (mEq/L)<br>Glucose (mg/dL) | mEq/L | **Correction factor:** 1.6 mEq/L per 100 mg/dL glucose rise<br>Used in DKA management |
| **Corrected Sodium (Hillier)** | Corrected Na⁺ = Measured Na⁺ + [2.4 × (Glucose - 100)/100] | Measured Na⁺ (mEq/L)<br>Glucose (mg/dL) | mEq/L | **Correction factor:** 2.4 mEq/L per 100 mg/dL glucose rise<br>**More accurate when glucose >400 mg/dL** |
| **Transtubular Potassium Gradient (TTKG)** | TTKG = (Urine K⁺ × Plasma Osm) / (Plasma K⁺ × Urine Osm) | Urine K⁺ (mEq/L)<br>Plasma K⁺ (mEq/L)<br>Urine Osmolality (mOsm/kg)<br>Plasma Osmolality (mOsm/kg) | Ratio (unitless) | **Infants (1 mo-1 yr):** Median 7.8, range 4.1-13.4<br>**Children (>1-15 yr):** Median 6.0, range 4.1-13.4<br>**Interpretation:** TTKG <7 in hyperkalemia suggests hypoaldosteronism |
| **Fractional Excretion of Urea (FEUrea)** | FEUrea = [(Urine Urea × Plasma Cr) / (Plasma Urea × Urine Cr)] × 100 | Urine Urea (mg/dL)<br>Plasma Urea/BUN (mg/dL)<br>Urine Creatinine (mg/dL)<br>Plasma Creatinine (mg/dL) | % | **FEUrea <35%:** Prerenal azotemia<br>**FEUrea >35-50%:** Intrinsic renal disease/ATN<br>**NOT affected by diuretics** |
| **Renal Failure Index (RFI)** | RFI = (Urine Na⁺ × Plasma Cr) / Urine Cr | Urine Na⁺ (mEq/L)<br>Plasma Creatinine (mg/dL)<br>Urine Creatinine (mg/dL) | Ratio or % | **RFI <1% (<0.01):** Prerenal causes<br>**RFI >1% (>0.01):** Intrinsic renal causes (ATN) |
| **Free Water Deficit** | FWD = TBW × [(Measured Na⁺ / Desired Na⁺) - 1] | TBW = 0.6 × Weight (kg)<br>Measured Na⁺ (mEq/L)<br>Desired Na⁺ = 140-145 (mEq/L) | Liters | **Alternative:** [(Current Na⁺ - 145) / 145] × 0.6 × Wt (kg)<br>**Correct over 48-72 hours**<br>Max decrease: 0.5 mEq/L/hr or 10-12 mEq/L/24hr |

## ACID-BASE SYSTEM

| Equation Name | Formula | Variables | Units | Age-Specific Modifications |
|--------------|---------|-----------|-------|---------------------------|
| **Henderson-Hasselbalch Equation** | pH = 6.1 + log([HCO₃⁻] / [0.03 × PaCO₂]) | HCO₃⁻ = Bicarbonate (mEq/L)<br>PaCO₂ = Arterial CO₂ (mmHg)<br>6.1 = pKa of carbonic acid<br>0.03 = Solubility constant | pH units | **Normal pediatric pH:** 7.35-7.45<br>**Neonates:** 7.32-7.42 (slightly lower)<br>**Preterm:** May be 7.25-7.35 initially |
| **Base Excess (BE)** | BE = (HCO₃⁻ - 24.4) + [2.3 × Hgb + 7.7] × (pH - 7.4) | HCO₃⁻ = Bicarbonate (mEq/L)<br>Hgb = Hemoglobin (g/dL)<br>pH = Blood pH | mEq/L | **Normal:** -2 to +2 mEq/L<br>**Metabolic acidosis:** BE < -2<br>**Metabolic alkalosis:** BE > +2<br>**Neonates:** Wider range (-4 to +2 mEq/L) |
| **Standard Base Excess (SBE)** | SBE = 0.93 × (HCO₃⁻ - 24.4) + 14.8 × (pH - 7.4) | HCO₃⁻ = Bicarbonate (mEq/L)<br>pH = Blood pH | mEq/L | **Normal:** -2 to +2 mEq/L<br>Independent of hemoglobin<br>Better reflects metabolic component |
| **Expected PaCO₂ (Metabolic Acidosis)** | Winter's Formula:<br>Expected PaCO₂ = 1.5 × (HCO₃⁻) + 8 ± 2 | HCO₃⁻ = Bicarbonate (mEq/L) | mmHg | **Assesses respiratory compensation**<br>If actual PaCO₂ > expected: inadequate compensation<br>If actual PaCO₂ < expected: concurrent respiratory alkalosis<br>**Valid in children >1 year** |
| **Expected HCO₃⁻ (Respiratory Acidosis)** | **Acute:** Δ HCO₃⁻ = 0.1 × Δ PaCO₂<br>**Chronic:** Δ HCO₃⁻ = 0.35 × Δ PaCO₂ | Δ = Change from normal (40 mmHg for PaCO₂, 24 mEq/L for HCO₃⁻) | mEq/L | **Acute (<6 hours):** Minimal metabolic compensation<br>**Chronic (3-5 days):** Renal compensation<br>**If HCO₃⁻ higher than expected:** Concurrent metabolic alkalosis |
| **Expected HCO₃⁻ (Respiratory Alkalosis)** | **Acute:** Δ HCO₃⁻ = 0.2 × Δ PaCO₂<br>**Chronic:** Δ HCO₃⁻ = 0.4 × Δ PaCO₂ | Δ = Change from normal (40 mmHg for PaCO₂, 24 mEq/L for HCO₃⁻) | mEq/L | **Acute (<6 hours):** Minimal metabolic compensation<br>**Chronic (2-3 days):** Renal compensation<br>**If HCO₃⁻ lower than expected:** Concurrent metabolic acidosis |
| **Bicarbonate Deficit** | HCO₃⁻ Deficit = 0.3 × Weight (kg) × Base Deficit | Weight (kg)<br>Base Deficit = 24 - Current HCO₃⁻ (mEq/L) | mEq | **Give 1/2 deficit over first 3-4 hours**<br>**Neonates:** Use 0.5 × Weight × Base Deficit<br>**Recheck ABG and adjust** |
| **Bicarbonate Deficit (Alternative)** | HCO₃⁻ Deficit = 0.5 × Weight (kg) × (Desired HCO₃⁻ - Actual HCO₃⁻) | Weight (kg)<br>Desired HCO₃⁻ = 15-18 (mEq/L)<br>Actual HCO₃⁻ (mEq/L) | mEq | **More conservative estimate**<br>**Goal:** HCO₃⁻ = 15-18 mEq/L, not full correction to 24<br>**Max infusion rate:** 1 mEq/kg/hr |
| **Anion Gap (AG)** | AG = Na⁺ - (Cl⁻ + HCO₃⁻) | Na⁺ = Sodium (mEq/L)<br>Cl⁻ = Chloride (mEq/L)<br>HCO₃⁻ = Bicarbonate (mEq/L) | mEq/L | **Normal:** 8-12 mEq/L<br>**High AG metabolic acidosis (MUDPILES):**<br>Methanol, Uremia, DKA, Propylene glycol, Iron/INH, Lactic acidosis, Ethylene glycol, Salicylates |
| **Delta Gap (Δ Gap)** | Δ Gap = (Measured AG - 12) - (24 - Measured HCO₃⁻) | AG = Anion Gap (mEq/L)<br>HCO₃⁻ = Bicarbonate (mEq/L)<br>12 = Normal AG<br>24 = Normal HCO₃⁻ | mEq/L | **Δ Gap = 0:** Pure high AG metabolic acidosis<br>**Δ Gap < -6:** Concurrent normal AG acidosis<br>**Δ Gap > +6:** Concurrent metabolic alkalosis<br>**Identifies mixed disorders** |
| **Corrected HCO₃⁻** | Corrected HCO₃⁻ = Measured HCO₃⁻ + (Measured AG - 12) | HCO₃⁻ (mEq/L)<br>AG = Anion Gap (mEq/L) | mEq/L | **If corrected HCO₃⁻ >28:** Concurrent metabolic alkalosis<br>**If corrected HCO₃⁻ <22:** Concurrent normal AG acidosis<br>**Used in high AG acidosis** |
| **CO₂ Content** | CO₂ = HCO₃⁻ + (0.03 × PaCO₂) | HCO₃⁻ = Bicarbonate (mEq/L)<br>PaCO₂ = Arterial CO₂ (mmHg)<br>0.03 = Solubility constant | mEq/L or mmol/L | **Total CO₂ content on chemistry panel**<br>≈ HCO₃⁻ + dissolved CO₂<br>**Normal:** 23-29 mEq/L |

## NEUROLOGICAL SYSTEM

| Equation Name | Formula | Variables | Units | Age-Specific Modifications |
|--------------|---------|-----------|-------|---------------------------|
| **Cerebral Perfusion Pressure (CPP)** | CPP = MAP - ICP | MAP = Mean Arterial Pressure (mmHg)<br>ICP = Intracranial Pressure (mmHg) | mmHg | **Target CPP:**<br>• 0-5 years: >40 mmHg<br>• 6-11 years: >50 mmHg<br>• 12-17 years: >50-60 mmHg<br>• ≥18 years: 60-80 mmHg (normal) |
| **Mean Arterial Pressure (MAP)** | MAP = [(2 × DBP) + SBP] / 3 | SBP = Systolic BP (mmHg)<br>DBP = Diastolic BP (mmHg) | mmHg | **Normal adult:** 70-100 mmHg<br>**Neonates:** Lower; MAP ≈ gestational age (weeks) on day 1 |
| **Intracranial Pressure (ICP) - Direct Measurement** | ICP = Direct transducer measurement | Measured via invasive monitor | mmHg or cmH₂O | **Normal values:**<br>• Adults: 7-15 mmHg<br>• Children (>1 yr): <10-15 mmHg<br>• Infants (0-1 yr): <6-10 mmHg<br>**Treatment threshold:** ICP >20 mmHg |
| **Pressure Reactivity Index (PRx)** | PRx = Correlation coefficient between slow waves of ICP and MAP | Continuous ICP and MAP measurements<br>Moving correlation over time | Dimensionless (-1 to +1) | **PRx ≈ 0 or negative:** Intact autoregulation<br>**PRx > 0.2-0.3:** Impaired autoregulation<br>Higher PRx associated with worse outcomes in pediatric TBI |
| **RAP Index (Compensatory Reserve)** | RAP = Correlation between ICP pulse amplitude (A) and mean ICP (P) | A = ICP pulse amplitude<br>P = Mean ICP | Dimensionless (-1 to +1) | **RAP ≈ 0:** Good compensatory reserve<br>**RAP → +1:** Poor reserve (low compliance)<br>**RAP = +1:** Exhausted reserve |
| **Cerebrovascular Resistance (CVR)** | CVR = CPP / CBF | CPP = Cerebral Perfusion Pressure (mmHg)<br>CBF = Cerebral Blood Flow (mL/100g/min) | mmHg/(mL/100g/min) | When autoregulation intact: CVR varies inversely with CPP<br>Children with worse outcomes show impaired CPP-CVR correlation |
| **Pulsatility Index (PI) - TCD** | PI = (PSV - EDV) / MFV | PSV = Peak Systolic Velocity (cm/s)<br>EDV = End Diastolic Velocity (cm/s)<br>MFV = Mean Flow Velocity (cm/s) | Dimensionless ratio | **Normal PI:** 0.5-1.2 (age-dependent)<br>**Elevated PI (>1.4-1.5):** Suggests increased ICP<br>**Pediatric TBI:** 100% sensitive, 82% specific for ICP >20 mmHg (day 1) |
| **Brain Tissue Oxygen (PbtO₂) - Target** | PbtO₂ = Direct tissue measurement | Direct probe measurement | mmHg | **Adult target:** >10 mmHg<br>**Pediatric observations:** PbtO₂ >30 mmHg may be associated with better outcomes<br>**Critical:** <5 mmHg for >1 hour = poor outcome |
| **Hypotension Threshold (Pediatric)** | SBP threshold = 70 + (2 × age in years) | Age (years) | mmHg | **Age-specific hypotension:**<br>• <1 year: SBP <65 mmHg<br>• 1-5 years: SBP <75 mmHg<br>• 6-11 years: SBP <80 mmHg<br>• 12-17 years: SBP <90 mmHg |

## NUTRITIONAL/METABOLIC SYSTEM

| Equation Name | Formula | Variables | Units | Age-Specific Modifications |

## NOTES ON CLINICAL APPLICATION

### Key Points for Pediatric/Neonatal Use:

**1. Age-Dependent Variables:**
- Nearly all equations have age-specific constants or normal values
- Neonatal values often differ significantly from older children
- Always verify appropriate age range before applying formulas

**2. Weight-Based Dosing:**
- Most pediatric calculations normalize to body weight (per kg)
- Body Surface Area (BSA) indexing used for cardiac parameters
- Consider using actual vs ideal body weight in obesity

**3. Neonatal Considerations:**
- Higher blood volumes per kg (80-100 mL/kg)
- Different MAP calculation (use average of systolic/diastolic)
- Calcium correction formulas unreliable <3 months
- Osmolality formulas less accurate <3 months
- Physiologic weight loss up to 5% in first 10 days
- FENa thresholds differ (<2.5% prerenal in term, <3% in preterm)

**4. Critical Illness Adjustments:**
- Energy requirements change by illness phase (acute/stable/recovery)
- Indirect calorimetry (Weir formula) is gold standard when available
- Fluid requirements may need adjustment for fever, losses, disease state
- Transfusion thresholds vary based on clinical condition

**5. Monitoring and Safety:**
- Serial measurements more valuable than single calculations
- Formulas provide estimates with ±5-15% error margins
- Clinical judgment essential - formulas supplement, not replace, assessment
- Use age-appropriate reference ranges for interpretation

**6. Equipment Considerations:**
- Smaller endotracheal tubes increase airway resistance significantly
- Dead space relatively larger in neonates
- Circuit compliance affects delivered tidal volumes
- Modern creatinine assays require updated Schwartz equations

**7. Acid-Base Interpretation:**
- Always assess pH, PaCO₂, and HCO₃⁻ together
- Use anion gap to differentiate metabolic acidosis types
- Apply compensation formulas to identify mixed disorders
- Consider delta gap in high anion gap acidosis
