## Design Standard

All interactive decision trees follow the **Clinical Decision Tree Standard**:

- **Engine**: D3.js 7.8.5 interactive collapsible tree
- **Theme**: Dual light/dark mode with CSS custom properties (`data-theme` attribute)
- **Banner**: Configurable via CSS variables (`--banner-*`), JS API (`setBannerTheme()`), or parent frame inheritance (`inheritBannerFromParent()`)
- **Fonts**: DM Serif Display (headings), IBM Plex Sans (body), IBM Plex Mono (data)
- **Node Colors**: Emergency=red, Urgent=orange, Decision=yellow, Action=green, Assessment=blue, Diagnosis=purple
- **Info Panels**: ⓘ badge on each node opens popup with tabbed panels (protocols, dosing tables, evidence boxes with DOI citations, alert callouts)
- **Education Links**: 📚 Resources panel linking to education guides, textbooks, audio textbooks, and cheat sheets in the same repository
- **Single-file HTML**: No external dependencies beyond CDN fonts and D3.js

## Embedding in Your Website

### Option 1 — Direct iframe
```html
<iframe src="glucose-management/index.html" width="100%" height="800px" frameborder="0"></iframe>
```

### Option 2 — CSS Banner Override
Add a `<style>` block after the file's styles:
```css
:root, [data-theme] {
  --banner-bg: #1a3c6e;
  --banner-text: #ffffff;
  --banner-accent: #4da6ff;
  --banner-border: #2a5598;
}
```

### Option 3 — JavaScript API
```javascript
setBannerTheme({
  bg: '#1a3c6e',
  text: '#ffffff',
  accent: '#4da6ff',
  title: 'My Hospital — Neonatal Protocol',
  subtitle: 'Level II Nursery',
  logoUrl: 'https://...'
});
```
