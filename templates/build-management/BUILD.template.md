## How to change this document

1. Add or edit a feature in [`.build/manifest.yaml`](.build/manifest.yaml) on a branch.
2. Open a PR. CI validates the manifest against `.build/schema.json`.
3. On merge, `build-md-render.yml` regenerates this file.

To **order a gap analysis** (propose new features automatically), run the
**Gap Analysis Request** workflow from the Actions tab. It opens a PR with
proposed `GAP-NNN` and `FEAT-NNN` entries. **Merging the PR = approval.**
